# Public demo media

These four images are cropped screenshots from the real-room editor's saved decor demonstration. The video is an H.264 feature tour assembled from those screenshots with `scripts/build_demo_video.py`; it is not a continuous screen recording. They show the prototype's actual soft photographic layer and actual UI controls. The raw scan, reconstructed model, saved revision JSON, local paths, and scan IDs are not present here.

The user authorized a public-facing demo of this room. The media is the only deliberately released visual excerpt of the private capture; the underlying data remains Git-ignored.
